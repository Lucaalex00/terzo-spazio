# apps/web

The public website of **Terzo Spazio di Giulia Bordino** (Next.js, App Router).

Setup, scripts and project overview live in the [root README](../../README.md);
architecture and rules in the root constitution documents. Working notes for
this app are in [CLAUDE.md](./CLAUDE.md).

Brand assets are in `public/brand/`: the original logo artwork, the app icons
and the social share image. The vector logo used on the site is defined in
`src/lib/brand.ts`.
